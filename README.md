# TypeWasher™

a music daw tool / sound design tool that'll work like a washing machine - when it'll work like one
simply you as user making your song, and then getting a clean result out, its simple - and efficient


TypeWasher™ is a music creation workstation / sound design tool that will eventually be downloadable software, TypeWasher™ name and its application as a Digital Audio Workstation/Audio Platform is (™) claimed by the author

## Features
- You can make your own instruments from components (drag and drop interface node-based)
- Custom scripting to create custom synthesisers on top of the existing blocks
- You can compose songs in the daw mode, contains piano roll and other things
- Current internal build is windows only, project will be most likely moved under different engine therefore will take longer
